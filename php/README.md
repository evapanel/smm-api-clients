# SMM panel API client (PHP)

Install with Composer:

```bash
composer require evapanel/smm-api-client
```

See the [main README](../README.md) for usage, [`example.php`](example.php) for a
runnable example, and [The SMM Panel API Explained](https://evapanel.com/blog/smm-panel-api-explained)
for every action.
